خطوات تشغيل ونشر لعبة ZALVORA — زالفورا كـ تطبيق PWA:

1. فك ضغط هذا الملف في فولدر جديد.
2. انسخ ملف اللعبة (zalvora.html) في نفس الفولدر وغيّر اسمه إلى: index.html
3. افتح ملف pwa-snippets.html وانسخ الجزئين الموضحين بداخله إلى ملف index.html (جزء داخل <head> وجزء قبل </body>).
4. ارفع الملفات الخمسة التالية معاً على استضافة HTTPS (مثل GitHub Pages):
   - index.html
   - manifest.json
   - sw.js
   - icon-192.png
   - icon-512.png
5. افتح الرابط من الموبايل وسيظهر زر «ثبّت زالفورا على جهازك» تلقائياً.

ملحوظة عند التحديث مستقبلاً:
غيّر كلمة 'zalvora-v1' داخل ملف sw.js إلى 'zalvora-v2' ليصل التحديث تلقائياً لكل اللاعبين.
